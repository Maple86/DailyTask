# DailyTask 微信小程序

该目录是 DailyTask 的远程中继控制台。小程序不直接连接 Android，所有操作都写入 CloudBase，Android 通过 HTTP 拉取。

## 首次配置

1. 在微信公众平台注册小程序并取得 AppID。
2. 在微信开发者工具中导入本仓库根目录。
3. 将 `project.config.json` 中的 `appid` 替换为你的小程序 AppID。
4. 在微信开发者工具开通云开发，并记下 CloudBase 环境 ID。
5. 将 `miniprogram/config.js` 中的 `cloudEnv` 替换为实际环境 ID。
6. 右键 `cloudfunctions/relay`，选择“上传并部署：云端安装依赖”。
7. 在云函数控制台测试一次 `initCollections`，或手动创建 README 中列出的集合。
8. 在 CloudBase 控制台为 `relay` 配置 HTTP 访问服务。优先使用环境自带的免费默认域名，取得 Android 使用的中继地址；自定义域名属于付费套餐能力。
9. 编译小程序，点击“添加设备”生成 6 位配对码。
10. 在 Android 的“设置 → 远程中继”中填写中继地址、设备名称和配对码。

## 页面说明

- 首页：设备在线状态、电量和任务状态。
- 绑定页：生成 6 位配对码。
- 设备页：启动任务、停止任务、立即打卡、循环开关、指令状态。
- 考勤页：按日期查看打卡记录。
- 配置页：重置时间、目标应用、工作日、大小周和任务时间。

## 注意事项

- 小程序不能直接唤醒 Android APP，必须通过云端同步。
- 首次联调先用默认域名，默认域名免费但有访问频率、有效期和稳定性限制。
- 需要长期稳定或绑定自有域名时，再升级 CloudBase 付费套餐。
- 首次发布前请先在体验版验证 CloudBase HTTP 访问。
- 小程序生产环境建议使用 HTTPS 域名和固定环境 ID。
- 不要把设备 Token 放入小程序代码。
